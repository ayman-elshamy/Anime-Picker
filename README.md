# Anime Picker 🎌

A simple Android app that lets you choose an anime from a Spinner and search for it directly on Google.

## Features

* Select an anime from a Spinner.
* Search for the selected anime on Google.
* Simple and beginner-friendly Android project.

## Technologies

* Kotlin
* Android Studio
* XML
* Spinner
* Intent
* ArrayAdapter

## How It Works

1. Choose an anime from the Spinner.
2. The app gets the selected anime using its position.
3. An implicit Intent opens a Google search for the selected anime.
